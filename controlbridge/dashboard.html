How this works

Evidence

A synthetic record supplies a setting, collection status and timestamp.

Control

Python checks evidence quality first, then the public-access setting.

Assessment

The result records a reason and evidence ID so you can trace it back.

What this demo can and cannot establish

A pass covers this setting only. A failure does not prove public data exposure; container settings also matter. Unknown means there is not enough usable evidence to decide.

DORA, ISO 27001 and Grundschutz++ mappings are pending review. This is not a compliance certification. RoI export and incident assessment are not implemented.
